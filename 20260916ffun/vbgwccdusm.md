# 老年人警惕肌少症：保护肌肉健康

> 更新时间：2026-09-16 (UTC+8)

**护理科普 39**

肌少症是肌肉减少的简称，是指随着年龄的增长而出现的进行性全身肌肉减少，肌肉强度下降以及肌肉生理功能减退的综合征。

**肌少症对生活有哪些影响？**

肌少症对于老年人的生活质量影响非常大，他会导致肢体的力量减弱，失去平衡性，容易跌倒摔伤等。同时肌少症也会使人的免疫力下降，容易外感风寒，增加患心脑血管疾病及糖尿病的风险。

**肌少症常见症状有那些？**

肌力减退，活动能力下降，日常活动行走、坐、立、起困难。

容易发生跌倒、摔伤、骨折。

衰弱、乏力、肌肉松弛、皮肤皱褶增多、体重下降。

**简便识别肌少症的方法：**

教给有自理能力的老年人一种非常简便的识别方法，不借助任何工具就可以测量，“指环试验”具体方法是：我们坐在椅子上，让大腿与小腿成90度，双脚自然放在地面上，用自己双手的食指和拇指环绕围住小腿最粗的部位，看是否能够完全环绕围住。

如无法围住小腿，说明小腿的肌肉够饱满，患肌少症的风险相对较小。如能够环绕围住或者还有剩余空间，说明有患肌少症的风险。如果需要确诊是否患有肌少症，还请到正规医院就医。

**日常生活中怎样预防肌少症呢？**

1. 增加蛋白质的摄入量，蛋白质是合成肌肉的重要营养物质，是抵抗肌少症的物质基础。牛奶、瘦肉、蛋类、鱼类，大豆及其制品都是优质蛋白质的重要来源。

2. 保证摄入足够的钙，钙可以减缓骨质流失，防止肌肉萎缩。含钙量高的食物有牛奶、奶酪，豆制品，虾皮，小鱼干，绿叶蔬菜。

3. 补充维生素D，增加维生素D可以增强髋部肌肉的力量，老年人可以通过晒太阳，食物摄取或者遵医嘱服用补充维生素D的药物。

4. 积极锻炼，以抗阻力运动为主，还可以进行有氧运动或者平衡训练。建议每周锻炼3-4次，每次20-30分钟，根据自身情况制定运动方案，避免劳累。上肢锻炼可以选用抬举哑铃或者矿泉水瓶、弹力拉绳等。下肢锻炼可以选择坐位抬腿，静力靠墙慢蹲，或者蹬健身车等。锻炼前要先热身，循序渐进，避免跌倒和骨折的发生。

肌少症作为一种老年综合征是老年人衰弱、残疾、死亡的重要因素，应当引起广泛关注并积极预防。
