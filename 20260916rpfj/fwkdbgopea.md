# 宫腔镜

> 更新时间：2026-09-16 (UTC+8)

说起宫腔镜让不少人瑟瑟发抖，

有些人直言害怕疼痛，

有些人担心宫腔镜会损伤子宫，

今天我们聊一聊身怀多技的宫腔镜。

宫腔镜检查是用膨宫液体扩张宫腔，在纤维光源内窥镜直视观察子宫颈管、子宫颈内口、子宫腔及双侧输卵管开口；既可以准确取材送病理检查，又可以手术治疗。

**宫腔镜检查适应症**
1、异常子宫出血；2、可疑宫腔粘连及畸形；3、妊娠物残留；4、宫腔内占位病变；5、不明原因的不孕或反复流产；6、宫内节育器异常；7、宫腔内异物；8、宫腔镜术后评估。
**宫腔镜手术适应症**

1、子宫内膜息肉；

2、子宫黏膜下肌瘤及部分影响宫腔形态的肌壁间肌瘤；

3、宫腔粘连；

4、纵膈子宫；

5、子宫内膜切除术；

6、宫腔内异物取出：比如嵌顿的节育器或流产残留物；

7、宫腔镜引导下输卵管插管通液等。

宫腔镜是一种低危险性的微创手术，在子宫颈局部麻醉或静脉麻醉下通过阴道及宫颈的自然腔道实施手术，有着精准、微创、痛苦小、出血少的特点，既不会在皮肤上留下任何手术瘢痕，也不会影响卵巢功能。
